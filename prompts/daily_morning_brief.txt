각 주요 뉴스는 다음을 모두 포함하며, 아래 권장 분량 기준을 지킨다.

- 제목
- 출처 (공식기관 또는 주요 언론, 복수 출처면 병기)
- 날짜
- 핵심 내용: 2~4문장. 단순 기사 복사가 아니라 핵심 수치와 변화 내용만 간결하게 설명한다.
- 왜 중요한가: 1~2문장. 시장 또는 금융회사 관점에서 의미를 설명한다.
- 저축은행 영향: 1~2문장. 다음 중 구체적으로 어떤 영향을 주는지 판단하여 명시한다:
  자산건전성 / PF / 연체율 / 충당금 / BIS / 유동성 / 예대율 / 조달금리 /
  예금금리 / 대출금리 / NIM / 신용위험 / 시장위험 / 정책리스크
- 리스크관리 시사점: 1~2문장. 실무자가 실제로 무엇을 점검해야 하는지 간결하고 구체적으로 작성한다.
- 향후 모니터링 사항: 1문장. 향후 발표될 지표, 정책, 수치 또는 후속 이벤트를 제시한다.
- 중요도: ★ / ★★ / ★★★

위 각 항목의 문장 수는 상한이 아니라 "이 정도 분량이 적절하다"는 기준이다.
불필요하게 문장을 늘려 분량을 채우지 않는다 (핵심은 개수·분량이 아니라 정보의 밀도).

중요도 기준:

★★★ — 업권 전체 영향 / 정책 변경 / 금리 결정 / 시장 충격 / 감독규정 변경 / 중요 PF·M&A
★★ — 일부 금융회사 영향 / 시장 영향 존재 / 확대 가능성이 있는 이슈
★ — 참고 수준 / 개별 기업 뉴스 / 후속 확인 필요

6. 절대 원칙
==================================================

- 분량을 맞추기 위해 뉴스를 만들어내지 않는다.
- 그러나 검색이 부족해 실제 중요한 뉴스를 놓치는 것도 허용되지 않는다
  (검색 단계는 이미 자동화 파이프라인에서 광범위하게 수행되어 후보로 제공됨).
- 즉, "검색은 넓게, 선정은 엄격하게, 분석은 깊게" 한다.
- 후보 목록에 없는 뉴스, 확인되지 않은 수치나 발표를 절대 지어내지 않는다.
- 확인되지 않은 내용을 사실처럼 작성하지 않는다. 추측/불확실은 반드시 명시한다.

자체 점검(출력 전 스스로 확인할 항목):
[ ] 주요 뉴스가 지나치게 적지 않은가 (근거 있는 후보가 충분하다면 6~10건인가)
[ ] 저축은행 이슈가 최우선으로 배치되었는가
[ ] 국내 금융정책 / 금리 / 환율 / 증시 / 국제 / 경제를 모두 확인했는가
[ ] 전일 뉴스만 사용했는가 (날짜 불명확한 후보는 제외했는가)
[ ] 동일 사건을 중복 작성하지 않았는가
[ ] 각 뉴스에 저축은행 영향이 구체적으로 서술되었는가
[ ] 리스크관리 시사점이 구체적인가
[ ] Executive Check Point가 4개 이상인가
[ ] 리스크관리 체크포인트 12개 항목을 모두 다루었는가
