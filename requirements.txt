# Daily Morning Brief 자동화 스크립트(scripts/)가 사용하는 Python 의존성.
#
# 이전(Claude/Anthropic) 버전은 표준 라이브러리(urllib)만으로 REST 호출을
# 직접 구현해 별도 의존성이 없었다. Gemini API로 교체하면서 Google 공식
# Python SDK를 사용하므로 이 파일이 새로 필요해졌다.
#
# 주의 (패키지명 혼동 방지):
#   - google-genai        ← 이 프로젝트가 사용하는 패키지. import 시
#                            `from google import genai`로 사용한다
#                            (scripts/ai_client.py 참고). 현재 Google이
#                            공식적으로 유지·권장하는 SDK다.
#   - google-generativeai  ← 이전 세대의 별도 패키지(`import google.generativeai
#                            as genai` 형태로 사용). 이 프로젝트는 이 패키지를
#                            쓰지 않는다. 이름이 비슷해 혼동하기 쉬우므로
#                            반드시 "google-genai"만 설치한다.
#
# GitHub Actions에서는 `.github/workflows/daily-brief.yml`의 의존성 설치
# 단계(`pip install -r requirements.txt`)에서 이 파일을 사용하며, 그 다음
# 단계에서 실제로 import가 되는지까지 확인한다(설치 자체가 조용히 실패하거나
# 이 파일이 실제로는 설치 단계에 반영되지 않는 문제를 조기에 잡기 위함).
#
# 참고: 뉴스 검색(Tavily)은 여전히 표준 라이브러리(urllib)로 직접 REST 호출을
# 구현하므로(scripts/news_fetcher.py), 별도 패키지가 필요하지 않다.
#
# 버전은 2026-08 기준 실제 설치 확인된 google-genai(PyPI)를 기준으로,
# 지나치게 좁게 고정하지 않도록 최소 버전만 지정한다.
google-genai>=1.0.0
